# Tormang

Самостоятельное Android-приложение для чтения манги, манхвы, маньхуа и комиксов. Kotlin, Compose и Material 3. Android 8.0+ (API 26); compile/target SDK 35.

Это работающая реализация с настоящими источниками, базой данных, импортом, читалкой и фоновыми загрузками. Приложение не наполняет библиотеку демонстрационными данными. Онлайн из коробки доступен официальный каталог xkcd. Для своей манги используйте CBZ/ZIP или разрешённый каталог издателя.

## Что реализовано

- **Библиотека:** добавление/удаление, избранное, создание/переименование/удаление категорий, несколько категорий на книгу, поиск, фильтры избранного/непрочитанного, grid/list, пять сортировок, обложки, счётчики и последняя глава.
- **Обзор:** реальный API xkcd, пагинация и lazy loading, поиск по номеру и заголовку; Open Catalog с жанровым фильтром, сортировкой по названию/обновлению и подключением через HTTPS; локальные архивы.
- **Источники:** единый MangaSource с метаданными, capabilities и унифицированными моделями. Подключение/отключение каталогов данных; никаких загружаемых исполняемых расширений.
- **Карточка:** автор, художник, описание, жанры, статус, атрибуция, альтернативные названия в модели, главы, продолжение чтения, категории, избранное, три порядка глав, массовые скачивания и read/unread.
- **Читалка:** вертикальные страницы, horizontal, RTL, LTR, webtoon; double tap и pinch zoom, pan, fullscreen, яркость, ориентация, навигация по страницам, предзагрузка двух соседних страниц, автоматический переход глав, восстановление позиции.
- **Офлайн:** очередь WorkManager, последовательные загрузки, pause/resume/cancel/retry/delete, прогресс, скорость, объём; внутреннее хранилище или выбранная папка SAF. Частичные файлы не считаются законченной главой.
- **Импорт:** настоящие CBZ/ZIP через системный выбор файла, естественный порядок страниц, объединение архивов в серии, защита от выхода за каталог и чрезмерной распаковки.
- **История:** позиции и время чтения, продолжение, удаление записи/очистка без сброса прогресса.
- **Обновления:** ручные и периодические, поиск новых глав без потери прогресса, уведомления с runtime-разрешением Android 13+.
- **Трекинг:** локальный дневник, статус, оценка, заметки и автоматический счётчик прочитанных глав, в том числе после ручного read/unread.
- **Backup:** версия формата, экспорт/импорт через SAF, предварительная проверка, preview и транзакционное восстановление метаданных; история, категории, прогресс, настройки, источники и дневник.
- **Настройки:** light/dark/system/AMOLED, dynamic colors, русский/английский/системный язык, reader, Wi-Fi, папка загрузок, очистка кэша, privacy, обновления и уведомления.
- **Интерфейс:** оригинальная иконка и палитра, адаптивная сетка/навигационная панель, edge-to-edge, пустые состояния, ошибки и retry.

## Архитектура и структура

19 Gradle-модулей. Clean Architecture, MVVM, Repository Pattern; Hilt связывает контракты с реализациями. UI не имеет доступа к Room или Retrofit.

```text
app/                      запуск и Navigation Compose
core/common/              JVM-утилиты и безопасная распаковка
core/database/            Room, DAO, экспорт схемы
core/network/             Retrofit, OkHttp
core/preferences/         DataStore
core/designsystem/        тема, токены, RU/EN ресурсы
core/ui/                  переиспользуемые Compose-компоненты
feature/{library,browse,manga,reader,downloads,
         history,updates,settings,tracking,backup}/
domain/                   model, repository, usecase
data/                    local, remote, repository
```

Модели объединены в `domain/model`, без дублирующего пустого `core/model`. Слои внутри `data` — пакеты одного модуля. Подробности: [архитектура](docs/ARCHITECTURE.md), [исследование Mihon/Tachiyomi](docs/RESEARCH.md), [этапы реализации](docs/IMPLEMENTATION.md).

## Запуск

Требуются JDK 17, Android SDK Platform 35, Build Tools 35.0.0 и интернет для первой загрузки зависимостей.

1. Откройте корень проекта в Android Studio и дождитесь Gradle Sync.
2. Укажите SDK в `local.properties`: `sdk.dir=/absolute/path/to/android-sdk`. На текущей рабочей машине SDK установлен в `.tooling/android-sdk`; этот каталог не входит в Git.
3. Запустите модуль `app` на Android 8.0+ или соберите APK:

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый debug APK: `app/build/outputs/apk/debug/app-debug.apk`. Он подписан отладочным ключом. Для распространения нужна собственная release-подпись.

### Первый сценарий

1. Откройте «Обзор»: загрузится реальный xkcd.
2. Выберите произведение, добавьте в библиотеку и нажмите «Читать».
3. Для офлайн-чтения скачайте главу и дождитесь «Готово» в «Ещё → Загрузки».
4. Для манги выберите «Обзор → Импорт», введите название серии и выберите CBZ/ZIP. Следующий архив с тем же названием серии станет ещё одной главой.
5. Категории создаются в библиотеке и назначаются в карточке.
6. Экспорт находится в «Ещё → Резервная копия».

## Легальные интеграции

- [Официальный JSON API xkcd](https://xkcd.com/json.html) и [лицензия автора](https://xkcd.com/license.html). Контент загружается с серверов автора; атрибуция отображается в карточке. Лицензия CC BY-NC 2.5 содержит некоммерческое ограничение.
- Пользовательские архивы читаются локально.
- Издатель может разместить разрешённый HTTPS-каталог по [Open Catalog v1](docs/OPEN_CATALOG.md). Там приведены формат и порядок создания нового адаптера.

Приложение не обходит DRM, платный доступ, авторизацию или ограничения сайтов. Для OAuth-интеграции с издателем или трекером потребуется официальный API и регистрация приложения.

## Известные ограничения

- Это первая инженерная версия, а не обещание полного паритета с многолетними Mihon/Tachiyomi или готовности к публикации в магазине.
- Внешняя синхронизация AniList/MyAnimeList и APK-расширения Mihon отсутствуют. Реализованы локальный трекинг и каталоги данных. Подключение внешнего трекера — отдельная OAuth/API-интеграция.
- xkcd содержит комиксы, не большой каталог манги. В его API нет глобального поиска по заголовкам и рейтинга популярности: заголовки фильтруются в загружаемых страницах, номер ищется напрямую. Неподдерживаемые рейтинги не подменяются фиктивными.
- Open Catalog загружается целиком (до 8 МБ) с локальной пагинацией; для огромного каталога нужен отдельный серверный API-адаптер.
- Поддерживаются CBZ/ZIP, не CBR/RAR/PDF/EPUB. Локальные изображения не входят в JSON-backup; после переноса их необходимо импортировать снова.
- Reader масштабирует ограниченно декодированное изображение; тайлового декодирования сверхдлинных страниц нет. Реальная плавность на слабых устройствах требует профилирования.
- DataStore и Room не образуют общую транзакцию восстановления. При сбое между ними библиотека может восстановиться раньше настроек; повторный импорт завершает восстановление.
- Основной UI переведён на RU/EN; некоторые диагностические сообщения данных/сети остаются русскими или исходными сообщениями источника.
- Автоматические обновления зависят от Android/OEM, батареи и сети; время запуска не гарантируется. Новые Wi-Fi-настройки применяются к новым download jobs.
- Инструментальные проверки выполнены на Android 35 ARM64. Физические устройства, Android 8–14, TalkBack, SAF-провайдеры сторонних облаков и многодневные фоновые сценарии требуют отдельного тестирования.

## Дальнейшее развитие

1. Добавить разрешённый API издателя/собственного сервера и официальный OAuth-трекер с безопасным хранением токенов и отложенной синхронизацией.
2. Добавить тайловое декодирование длинных изображений, Macrobenchmark и baseline profile; измерить крупные библиотеки на слабых устройствах.
3. Ввести серверную пагинацию для больших каталогов, миграции Room при изменении схемы и потоковый backup больших библиотек.
4. Пройти матрицу устройств/версий, тесты SAF и accessibility; расширить локализацию ошибок.
5. Обновлять закреплённые зависимости совместимыми наборами, подготовить release-подпись и политику распространения.
